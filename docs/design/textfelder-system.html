  • ✓ Sichtbares Label immerÜber dem Feld, nie nur als Platzhalter (NN/g, WCAG 3.3.2)
  • ✓ ReihenfolgeLabel · Hinweis · Feld · Meldung (Fehler/Erfolg) · Zähler
  • ✓ KontrastLabel 17,9 · Hinweis 6,6 · Rand 3,5 : 1 (≥ 3 : 1, WCAG 1.4.11)
  • ✓ Fehler an der StelleText + Icon + roter 2-px-Rand unter dem Feld (6,6 : 1), nicht nur Farbe (WCAG 3.3.1)
  • ✓ Zustände vollständigStandard, Hover, Fokus, Fehler, Erfolg, Deaktiviert, Nur lesen
  • ✓ Fokus2-px-Rand + 3-px-Ring, 17,9 : 1; Dunkel weiß
  • ✓ Zielgröße44 px Standard (S 36, L 52), Abstand ≥ 8 px
  • ✓ Breite nach InhaltKurze Felder sind kurz (PLZ, Hausnummer), Standard volle Breite
  • ✓ Autocomplete und Typrichtiger type/inputmode und autocomplete (WCAG 1.3.5)
  • ✓ DunkelmodusRand ≥ 4,1 : 1, Schrift ≥ 5,6 : 1 auf Seite, Karte, erhöht
  • ✓ Nur lesen ≠ deaktiviertNur lesen: fokussierbar, kopierbar, wird gesendet; deaktiviert: nicht
  • ✓ Keine doppelte EingabeBekannte Angaben vorbelegen (WCAG 3.3.7)
