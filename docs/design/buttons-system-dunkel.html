Erfolgskriterien · geprüft

Quellen: Material Design Dark Theme, Apple HIG Dark Mode, WCAG 2.2 (1.4.3, 1.4.11), NN/g.

  • ✓ Gleiche Logik wie hellPrimär bleibt „Fläche + weiße Schrift“; nicht einfach invertieren (Apple)
  • ✓ Gedämpfte AkzenteGesättigte Töne mittlerer Helligkeit statt Pastell oder Neon (Material: Akzente entsättigen)
  • ✓ Schrift ≥ 4,5 : 1Weiß auf Primär 4,7 – 6,0 (Lila), 4,7 – 6,0 (Grün)
  • ✓ Fläche gegen Seite ≥ 3 : 1Primär in allen drei Zuständen ≥ 3,1 : 1
  • ✓ Auf allen Flächen lesbarTertiär/Text-Schrift auf Seite, Karte und erhöht ≥ 5,0 : 1 (Apple: erhöhte Fläche testen)
  • ✓ Dunkelgrau, nie SchwarzSeite #180f18, Karte #261926, erhöht #381d39: Tiefe durch hellere Flächen, nicht durch Schatten
  • ✓ Zustände sichtbarHover und Gedrückt dunkler (Weiß-Kontrast steigt), Fokusring weiß 18,7 : 1
  • ✓ Deaktiviert lesbarSchrift 4,9 : 1, gedämpfte Fläche
  • ✓ Wenig AkzentPro Ansicht eine Primär-Aktion, Rest zurückhaltend
  • ✓ Nutzerwahl bleibtHell/Dunkel-Schalter und Systemeinstellung (NN/g: Dunkel ist Präferenz, nicht für alle besser)

Hinweis: Die Fläche des Sekundär-Buttons hebt sich nur schwach von der Seite ab; er wird über seine Schrift (13,5 : 1) erkannt.
