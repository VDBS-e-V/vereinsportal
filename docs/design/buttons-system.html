2 · Zustände alle sechs je Rolle

Hover ändert die Fläche, Fokus zeichnet einen 3-px-Ring mit 2 px Abstand, „Lädt“ zeigt Spinner und Text in gleicher Breite, „Deaktiviert“ bleibt lesbar.

3 · Icons: mit und ohne Text jede Rolle in allen vier Formen

Nur Text · Icon links · Icon rechts · nur Icon (Standard, Hover, Fokus). Alle sind 44 px hoch. Ein Icon-Button ist 44 × 44 px und bekommt einen Namen (aria-label) und Tooltip. Gefahr erkennt man am Icon oder Text, nie nur an der Farbe.

Erfolgskriterien · geprüft

Quellen: WCAG 2.2 (1.4.3, 1.4.11, 2.4.7, 2.5.8), GOV.UK, Material 3, Designsystem-Praxis.

  • ✓ Eindeutige HierarchieFünf Rollen (Primär, Sekundär, Tertiär, Text, Gefahr), höchstens eine Primär-Aktion je Ansicht
  • ✓ Icons mit und ohne TextJede Rolle: nur Text, Icon + Text, Text + Icon, nur Icon (44 × 44, mit Namen)
  • ✓ Text-Button erkennbarUnterstrichen (2 px), Schrift 5,0 : 1; Hover 5,9 : 1 auf Fläche
  • ✓ Kontrast Schrift ≥ 4,5 : 1Primär 5,0 · Text 5,0 · Gefahr 6,6 · Sekundär 17,9 · Tertiär 5,0
  • ✓ Kontrast Fläche/Rand ≥ 3 : 1Primär 5,0 · Sekundär-Rand 17,9 · Dunkel-Rand 4,8
  • ✓ ZielgrößeStandard 44 px hoch, Icon-Button 44 × 44, kompakt 36 px; Abstand ≥ 8 px
  • ✓ Alle ZuständeStandard, Hover, Fokus, Gedrückt, Deaktiviert, Lädt
  • ✓ Sichtbarer Fokus3 px Ring, 2 px Abstand, 17,9 : 1 (hell) · 18,7 : 1 (dunkel)
  • ✓ Klare BeschriftungVerb, 1–3 Wörter, kein Umbruch; Icon-Button mit Namen
  • ✓ Zustand nie nur FarbeDeaktiviert und Lädt tragen Text/Spinner, Hover ändert Fläche
  • ✓ Kein Layoutsprung„Lädt“ hat dieselbe Breite wie „Standard“
  • ✓ Ein System, eine GrammatikRolle × Größe × Form, eckig, 4-px-Raster, nur Tokens
