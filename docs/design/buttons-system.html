VDBS Button-System · Grün und Lila

Vier Rollen, jede in beiden Farben. Alle Kontraste sind gerechnet und erfüllen die Erfolgskriterien.

Primär: dunkle Fläche, weiße Schrift · Sekundär: helle Fläche, Ink-Schrift · Tertiär: weiße Fläche, Schrift und Rand in Farbe · Text: nur Schrift in Farbe.

Erfolgskriterien · geprüft

Grün #057f5b (Aktion) · Lila #58275a (Marke) · Ink #0f172a. Quellen: WCAG 2.2 (1.4.3, 1.4.11, 2.4.7, 2.5.8).

  • ✓ Vier Rollen in zwei FarbenPrimär · Sekundär · Tertiär · Text, je in Grün (Aktion) und Lila (Marke)
  • ✓ Primär: dunkel + WeißSchrift ≥ 5,0 : 1 (Grün 5,0, Lila 11,3)
  • ✓ Sekundär: hell + InkInk auf Fläche ≥ 9,6 : 1
  • ✓ Tertiär: Weiß + Farbe + RandSchrift 5,0 / 11,3 : 1, Rand ebenso (≥ 3 : 1)
  • ✓ Text: nur FarbeSchrift 5,0 / 11,3 : 1; Hover mit Fläche und Unterstrich
  • ✓ Alle ZuständeStandard, Hover, Fokus, Gedrückt, Deaktiviert, Lädt, je Rolle und Farbe
  • ✓ Icons mit und ohne TextJe Rolle und Farbe vier Formen: nur Text, Icon + Text, Text + Icon, nur Icon
  • ✓ ZielgrößeStandard 44 px, Icon-Button 44 × 44, kompakt 36 px, Abstand ≥ 8 px
  • ✓ Sichtbarer Fokus3 px Ring, 2 px Abstand, 17,9 : 1 hell · 18,7 : 1 dunkel
  • ✓ DunkelmodusAlle Rollen ≥ 9,3 : 1 Schrift; Primär-Fläche gegen Seite ≥ 9,3 : 1
  • ✓ Kein Layoutsprung„Lädt“ hat dieselbe Breite wie „Standard“

Hinweis: Die Fläche des Sekundär-Buttons hebt sich nur schwach von Weiß ab (ca. 1,1 : 1). Der Button wird über seine Beschriftung (Ink, ≥ 4,5 : 1) und Größe erkannt, nicht über den Flächenkontrast.
