# Design Tools Polish

Die Designwerkzeuge bleiben bewusst klein und erzeugen keine parallelen
Komponentensysteme.

## Playgrounds

- Button-Playground: vorhandene Buttonvarianten
- Status-/Hinweis-Playground: Notice, Status und Badge
- Icon-Browser: zentrale Icon-Definitionen
- Code-Vorlagen: kopierbare Referenzsnippets

Der Copy-Button zeigt Erfolg jetzt sichtbar als `Kopiert` und kündigt ihn
zusätzlich über die bestehende Live-Region an.
