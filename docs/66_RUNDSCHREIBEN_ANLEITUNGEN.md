# Rundschreiben: Anleitungen in einfacher Sprache

Für Vorstand und Geschäftsstelle. Jede Anleitung ist eine Aufgabe.

---

## 1. Einladung zur Mitgliederversammlung verschicken

Wer: Vorstand.

1. Öffnen Sie im Bereich **Vorstand** die Seite **Rundschreiben**. Klicken Sie auf **Neues Schreiben**.
2. Wählen Sie bei **Gruppen** die Gruppe **Mitglieder**.
3. Wählen Sie oben eine **Vorlage**, zum Beispiel „Einladung zur Mitgliederversammlung“. Klicken Sie auf **Vorlage laden**.
4. Füllen Sie unter **Angaben zu Termin oder Versammlung** Titel, Datum, Uhrzeit und Ort aus. Die Platzhalter im Text (zum Beispiel `{datum}`) setzt das Portal selbst ein.
5. Setzen Sie bei einer Einladung das Häkchen **Pflichtmitteilung**. Dann bekommt jedes Mitglied die Einladung, auch wer sonst keine Post vom Verein will.
6. Klicken Sie auf **Vorschau**. Lesen Sie den Text und die Hinweise. Eine Warnung zur **Einladungsfrist** heißt: Zwischen Versand und Versammlung ist weniger Zeit als eingestellt. Prüfen Sie dann die Satzung.
7. Klicken Sie auf **An … Personen senden**. Wollen Sie später senden, tragen Sie vorher bei **Senden am** einen Zeitpunkt ein.
8. Öffnen Sie nach dem Versand die Seite des Schreibens und klicken Sie auf **Versandbescheinigung**. Drucken Sie sie für die Unterlagen.
9. Auf derselben Seite steht unter **Nicht erreichte Mitglieder**, wen Sie anders einladen müssen, zum Beispiel per Brief.

Wichtig: Die Bescheinigung zeigt, dass das Portal gesendet hat. Sie zeigt nicht, dass jede Person die Mail gelesen hat.

---

## 2. Nachricht an Teamende zu einem Seminar

Wer: Koordination.

1. Öffnen Sie im Bereich **Koordination** die Seite **Mitteilungen an Teamende**. Oder klicken Sie auf der Seminarseite auf **Teamende anschreiben**.
2. Wählen Sie das **Seminar** und den **Empfängerkreis**.
3. Die Geschäftsstelle hat einen festen Rahmen vorbereitet. Schreiben Sie nur Ihren eigenen Abschnitt dazu.
4. Klicken Sie auf **Vorschau**, dann auf **Senden**.

---

## 3. Eine große Nachricht von der Geschäftsstelle

Wer: Geschäftsstelle. Ab 50 Empfängern braucht die Nachricht die Freigabe des Vorstands.

1. Schreiben Sie die Nachricht wie in Anleitung 1. Klicken Sie auf **Zur Freigabe vorlegen**.
2. Der Vorstand bekommt eine Benachrichtigung und gibt frei oder gibt mit einer Begründung zurück.
3. Nach der Freigabe sendet das Portal. Zurückgegebene Nachrichten finden Sie als Entwurf unter **In Vorbereitung**.

Tipp: Mit **Als Entwurf speichern** unterbrechen Sie jederzeit und machen später weiter.

---

## 4. Wenn Mails nicht ankommen

1. Öffnen Sie die Seite des Schreibens. Unter **Fehlgeschlagene Zustellungen** stehen die Adressen.
2. **Fehlgeschlagene erneut versuchen** probiert es noch einmal.
3. **Nachfassen an nicht Erreichte** legt einen Entwurf mit denselben Adressen an, den Sie prüfen und senden.
4. Die Seite **Zustellqualität** zeigt, ob die Fehlerquote hoch ist. Dort prüfen Sie auch die Absenderadresse.

---

## 5. Was bedeutet Abmelden?

- Jede Mitteilung an Teamende oder Schulen enthält am Ende einen Link zum **Abbestellen**. Wer klickt, bekommt solche Mitteilungen nicht mehr. Der Link lässt sich wieder rückgängig machen.
- **Pflichtmitteilungen** an Mitglieder (zum Beispiel die Einladung zur Versammlung) haben keinen Link. Sie gehen an alle Mitglieder mit E-Mail-Adresse.
- Eine **gesperrte Adresse** bekommt gar nichts mehr. Das passiert bei dauerhaften Zustellfehlern, bei Beschwerden oder wenn Sie die Adresse selbst sperren. Gesperrte Adressen finden Sie unter **Gesperrte Adressen** im Bereich der Rundschreiben. Dort können Sie eine Sperre auch aufheben.
- Direkt ausgewählte Einzelpersonen bekommen eine Nachricht auch dann, wenn sie Sammelmitteilungen abbestellt haben. Gesperrte Adressen nie.
