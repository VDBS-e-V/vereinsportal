# Web Content Library — Referenzabschluss

Die Eintragsdetailseiten verbinden das Inventar jetzt mit der eigentlichen
Designreferenz.

Ein Eintrag kann zusätzlich enthalten:

- Link zur bestehenden Designsystem-Seite
- kopierbare Code-Vorlage
- automatisch ermittelte verwandte Bausteine über gemeinsame Tags

Die Registry bleibt die Quelle für Status, Nutzung, Grenzen und Accessibility.
`WebContentLibraryReference` enthält ausschließlich Referenz- und
Beispielinformationen und verändert keine Produktkomponenten.
